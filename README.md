 atividade-logica-adalberto

Atividade de lógica com Streamlit para verificar a situação do aluno.

## Como funciona
O app pede o nome do aluno e duas notas, calcula a média e mostra se foi Aprovado (média >= 6) ou Reprovado.

## Como executar
1. Instale o Streamlit: pip install streamlit
2. Rode o app: streamlit run app.py

## Tecnologias
- Python
- Streamlit
